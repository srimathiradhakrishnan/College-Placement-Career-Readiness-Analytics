# College Placement & Career Readiness Analytics

## Project Overview
This SQL project analyzes student placement data to understand
placement performance, student skills, and project completion.

## Tools Used
- MySQL
- MySQL Workbench

## Database Tables
1. Departments
2. Students
3. Skills
4. Student_Skills
5. Projects
6. Placements

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- JOIN
- LEFT JOIN
- GROUP BY
- ORDER BY
- HAVING
- COUNT, MAX, AVG
- CASE WHEN
- CREATE VIEW

## Key Findings
- Total Students: 5
- Placed Students: 3
- Unplaced Students: 2
- Placement Percentage: 60%
- Highest Salary: 5 LPA
- Average Salary: 4.43 LPA
- Most Common Skills: SQL, Python, Excel
- Completed Projects: 4

## How to Run
1. Open MySQL Workbench.
2. Connect to your MySQL server.
3. Open the SQL project file.
4. Run the SQL statements in order.

Note: The project uses sample data for learning purposes.
If the database already exists, running the CREATE statements
again may produce errors.
